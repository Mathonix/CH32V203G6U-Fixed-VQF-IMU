01 / Capabilities

面向嵌入式的完整姿态感知链路

从惯性数据采集、姿态融合到校准存储与通讯输出，整合于一套可构建的开源固件中。

∠

定点 VQF 姿态解算

提供响应、均衡、稳定三档参数，以及固定阈值 ZARU 航向保持模式。

◎

六面加速度计校准

支持加速度计六面校准；校准结果与参数配置均可持久化保存至 Flash。

↗

高速 UART 通信

USART2 以 2 Mbps 工作，支持 AA55 协议、参数配置与数据输出。

≋

CAN 数据输出

除 UART 外，固件还支持通过 CAN 通道输出数据。

⇧

UART OTA 升级

采用独立引导程序与应用镜像，支持通过 UART 更新应用固件。

⌁

SPI 惯性数据采集

使用 SPI 读取 LSM6DSV 的六轴惯性数据，供后续姿态融合处理。

03 / Getting started

编译、连接与固件部署

脚本同时构建应用程序与独立 Bootloader，不依赖 IDE 生成的 makefile。

从源代码编译

安装 Python 3 与 WCH RISC-V Embedded GCC 12 工具链，在仓库根目录运行：

python firmware/tools/build_ahrs.py \
  --toolchain "D:\\MounRiverStudio\\MounRiver_Studio2\\resources\\app\\resources\\win32\\components\\WCH\\Toolchain\\RISC-V Embedded GCC12\\bin"

也可以通过 RISCV_GCC_BIN 环境变量指定工具链的 bin 路径。

编译输出目录：firmware/obj/ahrs_real/

固件镜像与烧录地址

boot_stub.bin独立引导程序（BL） · 地址 0x08000000
CH32_AHRS_app.bin应用镜像（APP） · 地址 0x08000400 · UART OTA 使用此文件
版本 20261003h 的 README 记录：应用镜像 31,088 B，引导程序 996 B。烧录前请确认使用与硬件匹配的固件。

串口接线

  1. 使用 USART2：PA2 = TX、PA3 = RX。
  2. WCH-Link UART 交叉连接 TX / RX，并确保共地。
  3. 串口参数设置为 2,000,000 baud · 8N1。

源码结构
